# brown-claude-marketplace

Brown의 Claude Code 플러그인 모음. 개인 개발용 스킬을 공개 마켓플레이스 형태로 관리합니다.

## 설치

```bash
# 마켓플레이스 추가 (최초 1회)
/plugin marketplace add https://github.com/kimyoon21/brown-claude-marketplace

# 플러그인별 설치
/plugin install idea-develop@brown-claude-marketplace
```

## 플러그인 목록

### idea-develop

아이디어·명세서를 제품으로 만드는 스킬 모음.

| 스킬 | 설명 | 트리거 |
|------|------|--------|
| productify | 제품 형태 결정 + 페이즈별 로드맵 설계 | "productify", "제품화", "로드맵 짜줘" 등 |

## 업데이트

```bash
/plugin update idea-develop@brown-claude-marketplace
```
